# Changelog

This release covers every change since 0.0.33. Versions 0.0.34 and 0.0.35 were published while `retend-gpui` was being prepared and are superseded by this release; upgrade directly from 0.0.33 to 0.0.36.

### Breaking changes

- Router events now extend `Event` instead of `CustomEvent`. Their data is on the event itself rather than on `event.detail`: read `event.from` and `event.to` on `routechange` and `beforenavigate`, `event.error` on `routeerror`, `event.lockedPath` and `event.attemptedPath` on `routelockprevented`, and `event.fullPath`, `event.title`, `event.replace` and the history lengths on `routeloadcompleted`. The `CustomEvent` fallback exported from `retend/context` has been removed ([de056cb](https://github.com/resuite/retend/commit/de056cbc1e1557b7c2b1c7d376c3b9f0ab026dc6)).
- `Outlet` no longer renders a `<retend-router-outlet>` element. It is now a logical group with no host element of its own, so it no longer accepts props or sets a `data-path` attribute, and CSS that targets `retend-router-outlet` no longer matches anything ([bc3b2bb](https://github.com/resuite/retend/commit/bc3b2bbfa91e6f4cada64f71eb155be1edb5187b)).
- Custom renderers: the `Renderer` interface drops `save()` and `restore()` and adds `getHandleNodes(handle)`. `Unique` now retains moved instances through renderer handles ([03e6171](https://github.com/resuite/retend/commit/03e6171189193d8d4d080745f46219d469c49142)).

### Native desktop apps with retend-gpui

`retend-gpui` is a new renderer that draws Retend components as native desktop interfaces through GPUI, with the same JSX, cells, control flow and router as on the web. This is its first public release and it is experimental: pin an exact version, and expect API changes before 0.1. Scaffold a project with `npx retend-start@latest my-app --target=gpui` ([22f6ec9](https://github.com/resuite/retend/commit/22f6ec9d6967e118f0b01850ccf3f8ede51ad9d2), [db02b61](https://github.com/resuite/retend/commit/db02b618246614b3a50e16b025f093ad7788d1a6), [116528c](https://github.com/resuite/retend/commit/116528cb466cce3d3c00df59385e67afaa16fb5e)).

- **Elements:** `div`, `button`, `input`, `textarea`, `img`, `svg` and `anchored`. Adjacent text renders as one wrapping run ([f4ddac5](https://github.com/resuite/retend/commit/f4ddac50cbc2204bdccc103adb255a5efd81b4c8), [383d165](https://github.com/resuite/retend/commit/383d1654a08f070ca1aef521b369fd306d8b469b), [0763cc4](https://github.com/resuite/retend/commit/0763cc43213e567fbe8fb9550163d54efe76cac5), [7f1ba4f](https://github.com/resuite/retend/commit/7f1ba4ff50e6d77d1c6f5f5e9eafe643c39f7203)).
  - `button`, `input` and `textarea` are native controls with default styling, focus and Tab traversal; `textarea` supports `minRows`/`maxRows` auto-sizing ([9a4a42d](https://github.com/resuite/retend/commit/9a4a42d3a89e04746614b354bc0a1114aff2358f)).
  - `img` loads remote URLs and bundled assets, supports `objectFit`, and fires `load` and `error` ([8be70fd](https://github.com/resuite/retend/commit/8be70fd32c55935344d5a56262368f6019203de4), [c19df40](https://github.com/resuite/retend/commit/c19df400efe979c9f06f5745897401da74a9aefd), [2a1444f](https://github.com/resuite/retend/commit/2a1444fc3869906d569c10574c92cab520cf172d)).
  - `svg` draws single-color icons in the current text `color`, from inline markup (`content`, for example a `?raw` import) or a local file (`src`) ([18938cf](https://github.com/resuite/retend/commit/18938cfc9519d0370bf4145ada11d4d2ea0a083e)).
  - `anchored` positions menus, tooltips and other floating layers relative to their parent, with collision handling.
  - `alt` on `img` and `svg` sets the accessible label; an empty or missing `alt` marks the element as decorative ([44d9dc3](https://github.com/resuite/retend/commit/44d9dc3cfdeb0ed1b806d68467fe9f2a678f0937)).
- **Styling:** block and flex layout, sizing, spacing including logical shorthands, positioning, colors, opacity, borders, text styling, overflow with native scrollbars, and `hover`/`focused`/`active` styles ([a4952e4](https://github.com/resuite/retend/commit/a4952e4666687e7bd3f32b146fa77eb42ee61836), [dbc0160](https://github.com/resuite/retend/commit/dbc01603d26251be5f4f417889dcdd2fad0ebd7e)).
- **Motion:** native transitions for layout, color and transform properties, including cubic-bezier curves that overshoot, with `transitionrun`, `transitionstart`, `transitionend` and `transitioncancel` events. Transforms support `scale`, `rotate`, `translate`, `skew` and `transformOrigin` ([d67bd35](https://github.com/resuite/retend/commit/d67bd356d34a35680ed42466038d1c6af947d213), [cf65780](https://github.com/resuite/retend/commit/cf6578025455f7706052ccfb32f220dd9a642190), [5303e6d](https://github.com/resuite/retend/commit/5303e6d94db90a49ef46e924a9b2eea2d28c9335), [10b79ae](https://github.com/resuite/retend/commit/10b79ae94092af26aae01f2e3f6af5857f004a87), [01ea21f](https://github.com/resuite/retend/commit/01ea21fe6e31b50bf0db2c1e8923a6ca21243f77), [79320d7](https://github.com/resuite/retend/commit/79320d7c62398f67d6a2dd7041d74f7feed240cf)).
- **Events:** strongly typed pointer, keyboard, focus, input, scroll and `contextmenu` events, plus `mousedownoutside`, with capture and bubble phases and the usual event modifiers ([5077e41](https://github.com/resuite/retend/commit/5077e41b4d827b66761a561e2eeac140cdbe5920), [344ab00](https://github.com/resuite/retend/commit/344ab007ab50ee0d455119d000bdf4a3a453cea9)).
- **Applications and windows:** an application class with process-wide `context` read through `useAppContext()`, multiple independent windows through `useWindow()`, reactive window size and title, transparent titlebars and macOS fullscreen, and router support ([51febd9](https://github.com/resuite/retend/commit/51febd9957d792023e385c5a9bb228e8daac20c2), [295a649](https://github.com/resuite/retend/commit/295a649aa6d80e9356c0c66bd48cc788f285e0c2)).
- **Development:** `retend-gpui dev` runs the app under Vite with hot module replacement and an in-window error overlay. In development on macOS, the app shows its own name and icon in the Dock ([53128f4](https://github.com/resuite/retend/commit/53128f4166fc0f5817eb5dc12dba7f3bdb9e711e), [eb06db8](https://github.com/resuite/retend/commit/eb06db8711ea134904f5b070be0e31598d4b34ce), [d306521](https://github.com/resuite/retend/commit/d306521fd787141fa580c279505eaac3fca77c4e), [25df3fc](https://github.com/resuite/retend/commit/25df3fcf21a858c2e279fae07e058bdbe75074be)).
- **Distribution:** `vite build` packages a macOS `.app` and `.dmg`, with Developer ID signing and notarization, and a Windows `.exe` with icon and version resources ([b29bdea](https://github.com/resuite/retend/commit/b29bdea05bb55b1ec094c19214c59ab22e66b7db), [cd71604](https://github.com/resuite/retend/commit/cd716045383a95376ea61b9f9e85e0d64b5d2baf), [81babee](https://github.com/resuite/retend/commit/81babee6198ff85979450d99889c6163e8ba1ddb), [c1a122f](https://github.com/resuite/retend/commit/c1a122fac06f2ca927a18a9334756bfc4e145358), [a526178](https://github.com/resuite/retend/commit/a5261780500b837009d6b6c1a0cfce560c0c0fe2), [3823a19](https://github.com/resuite/retend/commit/3823a19c2089f2b2aba85be576452311dd5f3607)).
- **Platforms:** prebuilt binaries for macOS (Apple silicon), Windows (x64 and ARM64) and Linux (x64 and ARM64, experimental), installed automatically for the current platform. Intel Macs are not supported ([7cf2881](https://github.com/resuite/retend/commit/7cf28816b632277ec296a79a4029899f193ed81e), [ec17c8d](https://github.com/resuite/retend/commit/ec17c8d679809a6c9ad29a0de6887811711b8c75), [8cfd2bb](https://github.com/resuite/retend/commit/8cfd2bbf19b4c23ac0ffc5a8afb63698d2f44d9e)).
- Not supported yet: full-color inline SVG, CSS filters, and system integration such as the tray, global shortcuts, clipboard, file dialogs and notifications.

### Router

- Added the `linkTag` router option for rendering `Link` with a tag other than `a`, for renderers without anchors ([958c388](https://github.com/resuite/retend/commit/958c388f4a18ce33b633ab0582636fec20432124)).

### Scopes and HMR

- Fixed `useScopeContext` treating falsy provided values such as `0`, `''` or `false` as missing ([2455c2c](https://github.com/resuite/retend/commit/2455c2c122f47c5230d8f96d6634b69947a38dcc)).
- Component hot module replacement is now transactional: an update renders alongside the running UI and only replaces it if it succeeds, so a failed update keeps the last working UI on screen and reports the error ([6dd93f0](https://github.com/resuite/retend/commit/6dd93f03d42b4725fd26b7eb86c81f863c1b2839)).

### JSX types

- Moved the event modifier helper types (`EventModifier`, `EventModifierHandlers`) from `retend-web` into the shared `retend/jsx-runtime` namespace so every renderer can use them ([6514c53](https://github.com/resuite/retend/commit/6514c53965d98198f096eb25a4fabf8cb545da6f)).

- Both rules are in the recommended configuration.
