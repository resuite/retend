# Changelog

This release covers changes since 0.0.36.

### Breaking changes

- **Router attachment is now renderer-specific.** `Router.attachWindowListeners(window)` has been removed. Browser apps should import `attachRouter` from `retend-web` and call `attachRouter(router, window)`; GPUI apps should import `attachRouter` from `retend-gpui` and call `attachRouter(router, useWindow())`. Both return a cleanup function. The core router now exposes `router.sync(path)` for adopting a host URL without writing it back to history ([3df152d](https://github.com/resuite/retend/commit/3df152d68f49f18bd5061e49ad0afd358a5e650d), [4e38450](https://github.com/resuite/retend/commit/4e38450a6b12926b26306e62988f8d21d1a4646f)).
- **GPUI navigation no longer imitates the browser.** The window option `location` has been replaced by `initialPath`, which sets the starting route and does not change afterward. `window.host.location`, `window.host.history`, and the host's synthetic history events are gone. Use the router to navigate, and `attachRouter` to load `initialPath` and keep route titles in sync with the native window title ([4e38450](https://github.com/resuite/retend/commit/4e38450a6b12926b26306e62988f8d21d1a4646f), [c9da01d](https://github.com/resuite/retend/commit/c9da01db1915cde21d469677e8f8fa190692ad3e)).
- **GPUI resource events use `GpuiResourceEvent` instead of `GpuiImageEvent`.** Update imports or annotations for image `load`/`error` handlers. The new class also covers audio `ended` and `error` events ([5edb2a1](https://github.com/resuite/retend/commit/5edb2a13e0bb98e67c34145d92da67dc1b69260f)).

### GPUI: native controls and media

- Added a non-visual `<audio>` element for local audio files and imported assets. It supports reactive `src`, `autoPlay`, `loop`, `muted` and `volume` props; `play()`/`pause()` methods; and `ended`/`error` events. Audio decoding and playback run off the UI thread. Remote streams are not supported ([5edb2a1](https://github.com/resuite/retend/commit/5edb2a13e0bb98e67c34145d92da67dc1b69260f)).
- Added OS-native editing context menus for `input` and `textarea` on macOS and Windows, including Cut, Copy, Paste and Select All. macOS also integrates system spelling suggestions and supported Writing Tools. Registering `onContextMenu` lets an application replace the default menu ([f41238d](https://github.com/resuite/retend/commit/f41238d76c765811a836c6f17d975558d8b1c45b)).
- Added `useWindow().showMenu({ position, items })` for native popup menus on macOS and Windows. Menus support labeled actions, disabled items and separators; the promise resolves to the selected action ID or `null` when dismissed. Linux popup menus are not yet supported ([48291dc](https://github.com/resuite/retend/commit/48291dc22b70191e6456f9e188a71ebc0e15d734)).
- Ordinary rendered text can now be selected with the mouse and copied with the platform's keyboard shortcut. Use `style.userSelect: 'text' | 'none'` to control selection in a subtree. A selection is currently limited to one contiguous rendered text run, not multiple block elements ([0839134](https://github.com/resuite/retend/commit/08391346a74527d44241babf5df12b6dcc6fefcf)).

### GPUI: windows, input and styling

- Added `useSystem()` with reactive OS `theme` and `accentColor` Cells, and `useWindow().orientation` as a reactive `portrait`/`landscape` Cell. macOS applications can position the traffic-light controls with `system.trafficLightPosition` ([ef840ce](https://github.com/resuite/retend/commit/ef840ceb547bec253f4c732fa06e3587294adfda)).
- Added `onWheel` and `GpuiWheelEvent` for raw wheel and trackpad input, including deltas, pointer position, modifier keys and available touch phases. Unlike `onScroll`, this fires without requiring a scroll container; it does not cancel native scrolling ([ec54b36](https://github.com/resuite/retend/commit/ec54b36db7ae473dbdfefd0fc2d9604505400b8f)).
- Added `cursor` and `pointerEvents` styles for native pointer behavior, plus `style.placeholder.color` for `input` and `textarea` placeholders ([00d6b27](https://github.com/resuite/retend/commit/00d6b27c5827d5cefc523fe4f3cd6f8a3abfb745), [f41238d](https://github.com/resuite/retend/commit/f41238d76c765811a836c6f17d975558d8b1c45b)).
- Root-relative image paths such as `/logo.png` now resolve against Vite's `publicDir` in development. Packaged applications include those public assets in their resources ([6c916fb](https://github.com/resuite/retend/commit/6c916fb12e48df88e7295a1dc231739437dc542f)).

### Router and server rendering

- Routes containing only `path` and `redirect` can now match without a component or children ([489841f](https://github.com/resuite/retend/commit/489841f9efbc54625a8cd4216638d0a3bc0e3f8e)).
- Browser navigation now updates the document title when traversing history with the back and forward buttons, not just during direct navigation ([dcd4d3f](https://github.com/resuite/retend/commit/dcd4d3fc747386654ae9ffb048e2e5f31db0e3ee)).
- Separated browser history and title synchronization into `retend-web`; removed the server virtual DOM's browser-like `location` and `history` machinery. Updated Vite static-site generation module loading and route metadata handling ([3df152d](https://github.com/resuite/retend/commit/3df152d68f49f18bd5061e49ad0afd358a5e650d), [c9da01d](https://github.com/resuite/retend/commit/c9da01db1915cde21d469677e8f8fa190692ad3e), [980623e](https://github.com/resuite/retend/commit/980623e4f946157510755b861d4dd65a5f522199)).

### DevTools

- Added an **Open component definition** action to the inspector. The Retend Vite plugin now records component source locations so DevTools can open the selected component in the editor during development ([8e51498](https://github.com/resuite/retend/commit/8e514987a34014ac9cbb03cc8fc3fabfb7479c3a)).
- Fixed the DevTools panel disappearing after hot module replacement, and improved component-tree scrolling, panel spacing and inspector actions, including screenshot copying feedback ([897d44a](https://github.com/resuite/retend/commit/897d44a9dbbe9b2ffe83236f19a4743268f84dc2), [d6e55f8](https://github.com/resuite/retend/commit/d6e55f8050e8c936de719c17bb189172d6605686), [ab1892c](https://github.com/resuite/retend/commit/ab1892c86f686eaa029644d29e3a1209633af231)).

### Oxlint plugin

- Added `jsx-props-order` to the recommended rule set. It orders JSX attributes as `ref`/`key`, regular props, `class`, event handlers and function props, then `style`. A spread attribute restarts ordering for subsequent attributes ([fcf8648](https://github.com/resuite/retend/commit/fcf864852a7b5d5455f688e5288b07056852b05b)).

### Scaffolding and documentation

- GPUI projects generated by `retend-start` now use `attachRouter` and include `vite/client` types. When project docs are requested, the scaffold includes a local GPUI reference for elements, styling, windows and events ([4e38450](https://github.com/resuite/retend/commit/4e38450a6b12926b26306e62988f8d21d1a4646f), [980623e](https://github.com/resuite/retend/commit/980623e4f946157510755b861d4dd65a5f522199)).
- Rebuilt the documentation landing page, added dedicated GPUI reference pages, and revised the existing guides and visual components ([a3a6aef](https://github.com/resuite/retend/commit/a3a6aefa7e0263423a482a848e583a07bfc497b3), [4b6d743](https://github.com/resuite/retend/commit/4b6d7433205c76e753326cfa2478ac03a661eaf4), [e64c621](https://github.com/resuite/retend/commit/e64c621911c67a674de15ba50aca5aaeb127f33d)).

### Releases

- Added a version-driven GitHub Actions release workflow. When the package version changes on `main` and `AUTO_RELEASE_ENABLED` is set, CI verifies the changes, builds five native addon targets, packages and publishes the eight workspace packages and five native packages through npm Trusted Publishing, then creates a GitHub release using the versioned changelog and native artifacts. Publishing can resume after a partial failure without republishing existing npm versions ([f10152a](https://github.com/resuite/retend/commit/f10152a90214c356766a95f46c23b4ad40326af9), [d2451b1](https://github.com/resuite/retend/commit/d2451b16cba847d1af470be59fb5b9abb61abda8)).
