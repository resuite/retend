# Changelog

### Hydration and rendering

- Reimplemented hydration around serialized comment ranges, replacing `data-dyn` markers for deterministic structural matching ([1af3a67](https://github.com/resuite/retend/commit/1af3a6723b608ba86c73f4151ff26ce0326f2934)).
- Enforced strict structural matching in `hydrate`, removed the hydration attribute after completion, and switched teleport lookups from CSS selectors to attribute comparison so selectors with special characters resolve safely ([9fb9e98](https://github.com/resuite/retend/commit/9fb9e98b1a61c4365dcea50bc8d830e65fc67a78), [743f5e4](https://github.com/resuite/retend/commit/743f5e4ecfb3b284b86b2b8d6ea8756c41e01e24)).
- Streamlined the hydration sequence, simplified `renderToString` recursion, cleaned up hydration stack and state management in `DOMRenderer`, and refactored teleport counter and state initialization ([5f1f489](https://github.com/resuite/retend/commit/5f1f48968bdf9f551f1d79a703e2e1382235d85d)).
- Refactored UI components by standardizing node flattening with `.flat()`, improving `Await` promise tracking and disposal, fixing `For` loop initial node rendering, adding a `createSwitch` helper, and optimizing hydration data access and `If` component logic ([a65446e](https://github.com/resuite/retend/commit/a65446e18d3582a7f257559711326cfb79fdba02)).

### DevTools

- Extended the DevTools renderer and component tree to support multiple root nodes, updating search, picker, and highlight overlay logic along with click interception ([2bc4d8d](https://github.com/resuite/retend/commit/2bc4d8d4dec2a1e866d75bbab810b22f33969683)).

### Utilities

- Added `useResizeObserver()` for observing one or more element cells with the Resize Observer API, including automatic cleanup when the last observed element disconnects ([61d8f0a](https://github.com/resuite/retend/commit/61d8f0aeb3f53b334fb0d9eee684349d1bf28eff)).

### Oxlint plugin

- Added six new rules — `invalid-event-modifiers`, `no-async-component`, `no-cell-mutation-without-set`, `no-cell-type-alias`, `prefer-cell-task`, and `require-submit-prevent` — enabled them in the recommended preset, and added comprehensive unit tests ([99b5aed](https://github.com/resuite/retend/commit/99b5aed9f56d64a3dd67e21676834ad337ae4e9c)).

### Documentation

- Replaced the development mode section in the hydration docs with the new hydration contract ([1af3a67](https://github.com/resuite/retend/commit/1af3a6723b608ba86c73f4151ff26ce0326f2934), [9fb9e98](https://github.com/resuite/retend/commit/9fb9e98b1a61c4365dcea50bc8d830e65fc67a78)).
